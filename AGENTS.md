# Regras do Projeto JRX Seguros

- **Gerenciador de Pacotes**: Utilize SEMPRE o **`pnpm`** para gerenciamento de dependências e execução de scripts:
  - Instalação: `pnpm install`
  - Adição de pacotes: `pnpm add <pacote>` / `pnpm add -D <pacote>`
  - Execução de scripts: `pnpm dev`, `pnpm build`, `pnpm preview`
  - Não utilize `npm`, `yarn` ou `bun`.
